# Flask API Backend

A straightforward Python Flask API backend built for handling web services, routing, and JSON data. I put this together to build out backend service capabilities and practice RESTful architecture.

## Tech Stack
- Python 3
- Flask
- Git / GitHub
- Termux (developed and pushed locally)

## Endpoints
- `GET /` - Returns a basic status check and success message in JSON.
- `GET /api/leads` - Returns mock data representing backend lead handling.

## Running It Locally

Make sure you have Python and Flask installed, then run these commands in your terminal:

```bash
git clone [https://github.com/Techbhuti/flask-api-backend.git](https://github.com/Techbhuti/flask-api-backend.git)
cd flask-api-backend
pip install flask
python app.py
